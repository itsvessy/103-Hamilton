Vessy Home

Privacy policy

Last updated: September 21, 2026

This policy describes the personal Google Nest integration operated by itsvessy through Home Assistant. It is intended for the operator and authorized household users.

Information accessed

  • Identifiers and names of authorized homes, rooms, and supported Nest devices.
  • Available thermostat readings and settings, such as temperature, humidity, target temperatures, operating mode, and heating or cooling status.
  • Device-change events received through Google Cloud Pub/Sub, and the topic and subscription information needed to receive those events.
  • OAuth authorization tokens used to maintain the connection to Google. Google account passwords are entered on Google's pages and are not provided to this integration.

How information is used

Information is used to display device status, show device history, perform thermostat commands requested by household users, and run automations they configure. Pub/Sub access is used to set up and manage the event topics and subscriptions required by this integration.

Google user data is not sold, used for advertising, or used to train generalized artificial intelligence models.

Storage and access

Configuration, authorization tokens, and recorded device information are stored in the operator's Home Assistant installation. Backups can contain the same information and are stored in locations chosen by the operator. Access to the installation and its backups is managed by the operator.

Service providers and sharing

Google processes device requests and delivers events through its Nest and Google Cloud services. Tailscale provides remote connectivity to the private installation. Backup providers, if configured, process the backups stored with them. Information is made available to authorized household users and providers needed to operate these features.

This public information site is hosted by GitHub Pages. It contains no Nest device data, uses no analytics scripts, and sets no application cookies. GitHub may process website access logs under its privacy statement.

Retention and deletion

Device history and backups are retained according to the operator's Home Assistant and backup settings. Authorization tokens are retained while the connection is configured. Revoking access stops future authorized access but does not automatically erase previously recorded history or existing backups.

To disconnect, revoke the integration's device permissions in Google's Partner Connections Manager and remove the Google Nest integration from Home Assistant. The operator can separately delete stored history and backups when they are no longer needed.

Google API data use

Vessy Home's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and changes

For questions or deletion requests, contact the operator using the support email shown on the Google authorization screen. This policy will be updated if the integration's data practices change.
